SpaceScout is a simple TUI disk space analyzer that utilizes Go standart library for folders analyzing and BubbleTea package for TUI rendering.

This is simply my first Go project I made to learn Go syntax and its possibilities.
However I will continue developing new features.

Super simple roadmap includes:
  Beautiful visuals
  Additional scanning and displaying parameters
  Known bug fixing
Accepting proposals for features and bug fixes (if someone will even use this lol).
